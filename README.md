# DigitalOddities

> A living museum of digital curiosities, absurdities, and internet folklore

## What is DigitalOddities?

DigitalOddities is a community-driven GitHub repository dedicated to collecting, curating, and celebrating the strange, surreal, and fascinating artifacts of the digital age. Think of it as a museum for the internet—where broken buttons, glitched pixels, and digital folklore find a permanent home.

## Core Values

- **Low-barrier contribution**: Create content using only Markdown—no fancy tools required
- **Structured curation**: 10 rotating themes, updated weekly, to guide submissions
- **Open discussion**: Use GitHub Discussions for weekly topics, showcases, and community dialogue
- **Shareable formats**: ASCII art, emoji, tables, and text-based visuals that spread easily

## How to Contribute

### 1. Choose a Theme

We rotate through 10 sustainable themes, one per week:

| Theme | What to Submit | Example Formats |
|-------|----------------|----------------|
| `#404 Relics` | Broken web fragments, cache debris, expired buttons | Text descriptions, ASCII, tables |
| `#Pixel Anomalies` | Glitches, compression artifacts, distorted icons | Emoji art, text grids, ASCII pixels |
| `#Cache Oracles` | Error messages, system notifications, device prophecies | Plain text, formatted quotes, small tables |
| `#Table Hauntings` | Absurd statistics, weird rankings, fake administrative forms | Markdown tables, structured lists |
| `#ASCII Summoning` | Terminal sigils, keyboard landscapes, bracket labyrinths | Pure ASCII art, text patterns |
| `#Emoji Folklore` | Emoji rituals, digital customs, platform traditions | Emoji sequences, short explanations |
| `#Future Collection` | Museum-style artifacts, catalog entries, classification cards | Structured markdown, metadata fields |
| `#Algorithm Superstitions` | Traffic rituals, posting superstitions, platform folklore | Step-by-step guides, bulleted lists |
| `#Distorted Notices` | Absurd announcements, fake official statements | Formal notices, structured announcements |
| `#Cloud Urban Legends` | Digital ghost stories, forum myths, browser tales | Narrative prose, storytelling format |

### 2. Create Your Artifact

- Follow the template structure from existing exhibits
- Include: title, artifact ID, status, description, and interactive prompt
- Use only Markdown-compatible elements (no external images required)

### 3. Submit Your Contribution

- **Option A**: Open an Issue with your content
- **Option B**: Fork the repository and submit a Pull Request
- **Option C**: Share your idea in Discussions for feedback

## Community Guidelines

- **Respectful content only**: No personal attacks, harassment, or inappropriate material
- **Original work**: Submit your own creations or properly attributed adaptations
- **Keep it light**: Focus on the strange and absurd, not the harmful or offensive
- **Have fun**: This is a creative space—embrace the weirdness!

## Weekly Rhythm

1. **Monday**: New theme announcement in Discussions
2. **Week**: Community submissions via Issues/PRs
3. **Sunday**: Weekly showcase of featured artifacts
4. **Repeat**: 10-week cycle of rotating themes

## Get Involved

- **Join the discussion**: Participate in weekly topics on GitHub Discussions
- **Submit artifacts**: Share your digital curiosities with the community
- **Spread the word**: Share interesting exhibits on social media
- **Suggest improvements**: Open Issues for ideas to enhance the project
